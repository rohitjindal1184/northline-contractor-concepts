# Contractor Concept Showcase

- Scope: React landing-page gallery plus four complete contractor concept routes.
- Mode: Persuade.
- Audience: General contractors without a credible website, reached through cold outreach; each concept also demonstrates how it would persuade a homeowner.
- Job: Compare materially different website directions, open any concept, understand its conversion flow, and return to compare.
- Primary actions: Open a concept from the gallery; within a concept, request an estimate as the homeowner demo; from every page, schedule a website consultation through TidyCal as the outreach conversion.
- Proof/content: Authored architectural imagery, concrete service language, transparent process descriptions, and working demo form states. No fabricated testimonials, credentials, ratings, or project metrics.
- Constraints: Fictional reusable brand; React/Vite; responsive desktop and mobile; every concept needs a persistent route back to the gallery; forms remain front-end demonstrations; a route-themed top banner must open the shared TidyCal booking modal, which survives SPA route changes and provides a direct-link fallback.
- Chosen structure: Four-world showcase—Vertical Project Stories leads, followed by Daily Build Log, Architect's Field Book, and the familiar Category Standard.
- Memorable moment: The gallery behaves like a dark project table of complete websites, then each card opens into a fully committed world rather than a skin change.
- Critique references: `.impeccable/mocks/decision/challenger-vertical.webp`, `.impeccable/mocks/decision/assigned.webp`, `.impeccable/mocks/decision/model-pick.webp`, `.impeccable/mocks/decision/canon.webp`.
- Unresolved: Real contractor identity, region, credentials, phone, CRM destination, portfolio, and verified customer proof must be supplied before prospect-specific deployment.
